# Rodinný kalendár

Rodinný kalendár na tablet (Samsung Galaxy Tab S9 FE, na šírku): aktuálny týždeň, udalosti dňa, to-do list a slideshow s mesačným kalendárom po nečinnosti.

Beží ako webová aplikácia na GitHub Pages. Na tablete ju otvor v Chrome a pridaj cez ⋮ › „Pridať na plochu“; potom sa otvára na celú obrazovku bez lišty prehliadača.

Zatiaľ ukážkové dáta, napojenie na Google Kalendár príde neskôr.
